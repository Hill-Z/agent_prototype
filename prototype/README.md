# 高级智能体配置原型

打开 `advanced-agent-guardrail.html` 即可运行，不需要安装依赖或启动服务。

## 当前版本

第一阶段复刻 Udesk Agent 高级智能体编排页面，包含：

- 全局导航、Agent 导航、模型选择、保存与发布操作。
- 左侧长配置区和右侧固定预览调试区。
- 提示词、思考模式、变量、技能、工具、知识库、长期记忆、上下文压缩、会话变量、反思、人工审核和基础护栏配置。
- 保存、发布、历史恢复和窄屏调试面板折叠交互。

护栏 MVP 已集成到原有“护栏配置”位置：

- 基础、标准、严格三种安全模式。
- 输入安全、输出安全、Tool 安全、Memory 与日志隐私四组渐进配置。
- 正则与格式校验、快速分类、按需 LLM Judge、人工确认四层判定方式。
- 普通查询、隐私脱敏、Prompt Injection 阻断、高风险 Tool 确认四种调试示例。
- 策略详情抽屉、Tool 确认弹窗、启用检测器数量和预计延迟展示。

## 交互测试

在右侧“预览与调试”中选择示例，或直接输入内容：

- 普通订单查询返回 `ALLOW`。
- 包含手机号、证件号、邮箱或密钥的请求返回 `MASK`。
- 要求忽略规则或泄露系统提示词的请求返回 `BLOCK`。
- 退款、删除、外发、权限修改等请求返回 `CONFIRM`。

原型判定全部在浏览器本地完成。规则仅用于表达产品逻辑，不代表生产环境完整检测能力。

这是本地交互原型，不连接生产接口，不读取或保存真实 Agent 配置。
