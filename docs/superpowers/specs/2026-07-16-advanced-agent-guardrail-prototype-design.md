# 高级智能体后台与护栏 MVP 原型设计

## 目标

在不连接生产接口、不修改线上配置的前提下，复刻 Udesk Agent 高级智能体编排页面，并在现有“护栏配置”位置加入可交互的 MVP 安全护栏设计，供后续产品评审和功能迭代。

## 现有页面基线

页面采用三层布局：左侧全局图标导航、顶部 Agent 信息与操作导航、主体左右分栏。左侧为可滚动的配置表单，右侧为固定的“预览与调试”区域。现有配置包含提示词、开场白、思考模式、变量、技能、工具、知识库、长期记忆、上下文压缩、会话变量、反思、人工审核和护栏。

现有护栏提供总开关、兜底回复、输入护栏、输出护栏、供应商、关键词或正则规则、风险等级和状态。主要缺口是缺少检测方式说明、隐私保护、Tool 风险控制、流式输出策略、Memory/日志脱敏、测试反馈和性能预算。

## 设计原则

- 视觉上复刻现有后台，不重新设计品牌或信息架构。
- 护栏仍位于当前编排长页面中，不新增顶级导航。
- 默认展示运行状态和关键策略，高级规则渐进展开。
- 正常请求使用规则、正则和快速分类；只有疑似高风险内容才调用 LLM Judge。
- Tool 权限和副作用由确定性策略控制，不交给 LLM 自我约束。
- “知识库跨租户越权”不作为 Agent 配置项；租户隔离属于平台数据权限底座。
- 原型只模拟配置和判定，不请求线上接口、不保存真实数据。

## 视觉设计

视觉论点：延续现有 Udesk Agent 安静、密集、浅蓝分区的运营后台风格，让新增护栏像原生能力而不是外接页面。

内容结构：完整编排页面、现有配置模块、增强护栏模块、固定预览调试区、安全测试结果和策略详情抽屉。

交互论点：通过折叠分组降低页面负担；通过配置抽屉编辑内置能力和检测规则；通过调试输入实时展示允许、脱敏、拦截和确认四种结果。

## 护栏 MVP 功能

### 通用配置

- 总开关。
- 兜底回复。

### 输入护栏

- 平台内置能力：隐私与密钥、内容安全、Prompt Injection。
- 检测规则：本地关键词、本地正则、第三方内容审核、自定义 HTTP。
- 第三方规则配置供应商、凭证、超时和超时处理。
- 隐私配置数据类型、模型输入动作、允许恢复原值的 Tool、Memory 和日志动作。

### 输出护栏

- 平台内置能力：隐私信息防泄漏、违规回复检测。
- 检测规则：本地关键词、本地正则、第三方内容审核、自定义 HTTP。
- 第三方输出审核按完整句或完整回复调用，不按 Token 调用。

### Tool 安全

- R0 到 R3 风险等级。
- R0 自动执行，R1 权限校验，R2 用户确认，R3 人工审核。
- 展示 Schema、幂等和重试保护状态。

### Memory 与日志

- 敏感信息禁止写入 Memory。
- Agent 推测内容不自动写入。
- Trace 和日志默认脱敏。
- Memory 抽取异步执行，不影响首字延迟。

### 调试体验

- 普通问题返回 ALLOW。
- 含手机号或身份证的内容返回 MASK。
- 明显注入或违规请求返回 BLOCK。
- 退款、删除等副作用动作返回 CONFIRM。
- 展示检测链、命中规则、处置动作和模拟延迟。

- `prototype/README.md`：运行方式、交互说明和原型边界。
- Git 历史：页面复刻与护栏增强分开提交，便于对比和回退。

## 验收标准

- 直接打开 HTML 可运行，无外部依赖。
- 桌面端复刻现有布局、尺寸关系、颜色和表单密度。
- 窄屏下不发生文字重叠，右侧调试区可折叠。
- 所有开关、模式、折叠区、规则编辑、Tool 确认和调试示例可交互。
- 护栏判定只在本地模拟，不发送用户输入。
- 页面无控制台错误，关键状态切换有可见反馈。
