# 高级智能体安全护栏

## 1. 需求背景

高级智能体会接收用户输入、调用知识库和工具、生成回复，并将部分数据写入 Memory 与 Trace。仅依赖模型提示词不能稳定阻止隐私泄露、Prompt Injection、违规内容和高风险工具调用，需要在 Agent Loop 各关键边界提供可配置且可审计的安全策略。

## 2. 目标

1. 在输入、Tool、输出、Memory 与日志持久化前执行护栏。
2. 支持本地关键词、正则、平台内置检测和第三方安全服务。
3. 支持脱敏、阻断、用户确认、转人工和安全回复等动作。
4. 确定性规则优先，语义检测按需启用，控制正常请求延迟。
5. 每次决策可通过 Trace 追踪，但不在日志中记录敏感原文。

## 3. 前端功能

### 3.1 全局配置

- 启用安全护栏。
- 配置统一兜底回复。
- 平台强制规则始终生效，不随开关关闭，包括平台密钥、凭证和系统内部指令保护。

### 3.2 输入护栏

平台内置能力：

- 隐私与密钥：手机号、邮箱、证件号、银行卡、地址、API Key、Token 等。
- 内容安全：违法、色情、暴力、自伤、仇恨等。
- Prompt Injection：忽略规则、索取系统提示词、越权调用工具等。

自定义检测规则配置：

- 名称、状态、优先级、生效渠道和生效场景。
- 检测方式：关键词、正则、平台分类器、第三方服务。
- 命中动作：放行、脱敏、阻断、用户确认、转人工。
- 命中回复和测试样例。

### 3.3 输出护栏

- 配置敏感数据类型及输出动作。
- 配置禁止输出内容和业务禁答规则。
- 支持对输出执行脱敏、替换、安全回复、阻断或转人工。
- 流式回复必须经过增量检测，不允许先发送后撤回。

### 3.4 Tool 安全

- 工具风险等级：低、中、高。
- 配置允许调用的场景、角色、渠道和参数范围。
- 中高风险工具支持用户确认或人工审核。
- 工具参数发送前脱敏，Tool 返回进入模型和输出前再次执行护栏。
- 写操作必须使用幂等键，护栏不可用时拒绝高风险和写操作。

### 3.5 Memory 与日志隐私

- 敏感字段默认不写入长期记忆。
- 支持按数据类型配置“不保存、脱敏后保存、加密保存”。
- Trace 保存规则 ID、命中类型和动作，不保存密钥或完整敏感原文。

### 3.6 第三方检测

保留现有第三方检测能力，支持配置服务商、接口地址、鉴权引用、请求字段映射、响应结果映射、超时时间和失败策略。

鉴权只选择平台密钥引用，不在 Agent 配置中保存明文。测试功能使用脱敏后的样例数据。

## 4. 生效逻辑

### 4.1 输入阶段

```text
平台强制规则
-> 本地关键词/正则/密钥检测
-> 平台分类器与第三方检测按配置并行
-> 合并决策
-> 放行、脱敏后进入 Agent、要求确认、阻断或转人工
```

### 4.2 Tool 阶段

```text
工具选择
-> 调用条件与风险校验
-> 参数 Schema 与敏感字段校验
-> 用户确认/人工审核
-> 执行工具
-> Tool 返回护栏
-> 进入 Agent Loop
```

### 4.3 输出阶段

```text
模型输出增量缓冲
-> 本地敏感信息与控制标签检测
-> 可选语义/第三方检测
-> 脱敏、替换或终止
-> 渠道渲染与发送
```

流式检测保留跨分片重叠缓冲区，避免手机号、密钥和控制标签被拆分后漏检。需要完整语义判断的规则在结果返回前不得向客户发送对应内容。

### 4.4 决策合并

终止类动作优先于非终止类动作。同级规则按风险等级、规则优先级和规则 ID 稳定排序。脱敏可与放行组合；用户确认通过后仅恢复当前动作，不绕过后续 Tool 和输出护栏。

## 5. 性能与降级

- 本地规则在请求线程内执行，目标 P95 小于 10ms。
- 平台分类器和第三方检测并行执行，超时由规则配置，默认 1000ms。
- 低风险内容检测服务超时时可按配置放行或使用安全回复。
- 隐私密钥、高风险 Tool 和写操作必须 fail-closed。
- 第三方服务连续失败触发熔断和告警，避免每次请求等待完整超时。
- 护栏决策结果仅在规则版本、输入摘要和场景一致时短时缓存，不缓存敏感原文。

## 6. 后端模块

- Policy Service：保存规则、校验配置并提供运行时快照。
- Deterministic Scanner：关键词、正则、密钥格式和跨分片扫描。
- Provider Adapter：统一第三方安全服务请求与结果。
- Decision Engine：合并命中结果并输出标准动作。
- Redaction Engine：按数据类型执行掩码、删除或替换。
- Tool Gate：工具调用前风险、权限、参数和确认校验。
- Audit Sink：写入脱敏后的 Trace 与统计事件。

标准决策结果：

```json
{
  "decision": "MASK",
  "rule_ids": ["privacy.phone"],
  "risk_level": "medium",
  "redactions": [{"type": "phone", "replacement": "138****5678"}],
  "latency_ms": 6
}
```

## 7. Trace 与统计

Trace 记录：执行阶段、规则版本、检测器类型、规则 ID、风险等级、动作、第三方耗时、是否超时、降级策略和最终决策。

统计包括：检测请求量、命中率、各类型命中量、阻断率、脱敏率、确认率、转人工率、误判反馈、P95 延迟、第三方超时率和熔断次数。

## 8. 验收标准

1. 输入、Tool、输出、Memory/日志四个边界均执行对应护栏。
2. 手机号、邮箱、证件号、银行卡、API Key 和 Token 可按配置脱敏或阻断。
3. 关键词、正则、平台分类器和第三方检测均可配置并通过测试样例验证。
4. Prompt Injection 命中后不能读取系统提示词或越权调用工具。
5. 高风险工具未经确认不能执行；护栏异常时写操作默认拒绝。
6. 流式分片拆开手机号或密钥时仍能拦截，敏感片段不会先发送给客户。
7. 第三方检测超时按规则降级，并记录 Trace 和指标。
8. 日志、Trace 和 Memory 不出现密钥及完整敏感原文。
