# KM 转高级智能体上下文续接

KM 是存量 FAQ 机器人。客户由 KM 转入高级智能体、或再转回 KM 时，当前只传当次问题，导致重复追问、重复回答。

**需求**：转接时使用同一个会话 ID，KM 向高级智能体传递本次会话中按时间排序的客户输入、KM 实际回复及转接原因；高级智能体的回复再写回该会话，后续转接继续携带新增消息。

**双方改造**：KM 负责保存会话消息、发起转接并接收回复；高级智能体负责读取历史、基于历史处理并回传结果。每条消息需有消息 ID 和序号，重复请求不重复回复；历史缺失、乱序或读取失败时不启动高级智能体，KM 按现有兜底策略处理。

**验收**：客户在 KM 已问已答后转入高级智能体，不再被重复询问；双方来回转接不丢消息、不重复回复，且可按会话 ID 查询完整链路。
