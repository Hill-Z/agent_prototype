# Advanced Agent Frontend Prototype

Pure frontend React and TypeScript prototype of the Udesk advanced-agent configuration workspace. Configuration is persisted in browser `localStorage`; no backend is required.

Implemented prototype flows include prompt creation/library/generation, model parameters, variables, skills, tools, knowledge bases, memory, context compression, session fields, reflection, manual review, guardrails, preview traces, API documentation, logs, monitoring, and review-task filtering.

```bash
npm install
npm run dev
```

Verification:

```bash
npm test
npm run build
```
