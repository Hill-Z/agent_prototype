# 高级智能体多模态输入演示剧本

## 演示一：图片理解

1. 确认配置区“图片识别”已开启，模型为 `Doubao-Seed-2.0-pro`。
2. 点击调试输入框下方“图片”并选择任意 JPG/PNG 文件。
3. 输入“帮我看一下为什么失败”，点击发送。
4. 运行中展示“正在理解图片”，完成后展示“已识别 1 张图片”。
5. 展开识别结果，讲解图片摘要、OCR文字、模型及耗时。
6. 展示 Agent 根据截图给出的业务回复。

## 演示二：语音识别

1. 确认“语音与音频识别”已开启，ASR服务为 `Udesk ASR`。
2. 点击“语音”进入录音状态，对着麦克风说出问题并点击“完成录音”。
3. 短暂展示“正在识别语音”，识别完成后自动把转写内容填入输入框。
4. 修改或补充转写文字，然后点击发送。
5. 强调调试端语音是输入方式，不会形成待发送的音频文件。

## 演示三：图片与音频并行处理

1. 添加一张图片，再通过语音录入问题。
2. ASR文字回填后，可继续修改问题并与图片一起发送。
3. 发送后展示图片理解过程和识别结果。
4. 讲解正式IM中的语音不需要人工确认，将由渠道适配器下载后自动ASR并进入Agent。

## 异常状态口径

- 关闭图片识别后，图片入口禁用。
- 关闭音频识别后，音频入口禁用。
- 超出数量或时长时，正式产品应在上传阶段阻止并提示；当前原型只演示正常流程。
